# DARIA.EXE 4.1.0 — Product Office baseline

## Current release

v4.1.0 is the stable browser Product Office baseline on `main`.

The game moved from case-board / quiz-like interactions toward an explorable office with five product-judgement rooms:

- Research Lab
- Analytics
- Roadmap Room
- Experiment Bay
- Launch Room

The current release includes movement, room-specific mechanics, feedback, achievements and mobile controls.

## What is not part of this release

The following are experimental and are not considered production:

- raster Research Lab experiments;
- layered 2D art experiments;
- Unity Research Lab work;
- browser UX changes in `feature/product-office-tested`.

Those tracks must pass their own validation before promotion.

## Release gate

The current Product Office branch needs a fresh gameplay-oriented browser test suite before any new browser changes are promoted. Historical v3.x validation must not be treated as validation of v4.1 mechanics.
